## 4. 数据特征

### 4.1 会话结构
- 每个完整对话由一条用户提问 + 一条或多条客服回复组成
- 清洗后只保留有客服回复的对话

### 4.2 字段说明
| 字段名 | 说明 |
|--------|------|
| mail_id | 原始邮件ID |
| question | 用户提问内容 |
| answer | 客服回复内容 |
| inquiry_type | 自动提取的问题类型 |

## 5. 使用建议

- 该数据集适用于训练客服机器人或问答模型
- 训练集用于模型训练, 验证集用于效果评估
- 主要覆盖故障报告和购买问题, 可用于处理常见客服场景
